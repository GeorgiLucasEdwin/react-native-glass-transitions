# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability** ([direct link](https://github.com/GeorgiLucasEdwin/react-native-glass-transitions/security/advisories/new)). You'll get a reply within a week, and a fix or a decision on the report as soon as possible after that.

## Supported versions

Only the latest published version receives fixes.
